Genesis v1.0 marks the first Ascendra release and defines the project's initial experience. The browser-based design is intended for people who value a direct, uncomplicated workspace while providing a base for future improvements.

## Getting Started

### Use the hosted version

Launch the current hosted build in a modern browser:

[Download Ascendra v1.0](https://wardseanue7855.github.io/ascendra-productivity-hub/)

### Serve the project locally

First, clone the repository and move into the project folder:

```bash
git clone https://github.com/wardseanue7855/ascendra-productivity-hub.git
cd REPO
```

Ascendra is a web project, so its files should be made available through a local static server. After starting the server, open the local address it provides. One example using Python is:

```bash
python -m http.server 8000
```

Then browse to `http://localhost:8000` to open Ascendra.

Yes. Clone the repository, serve its files with a local static server, and open the resulting local URL in your browser.
